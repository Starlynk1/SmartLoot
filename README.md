# Smart Loot
---
```
This is a BETA. It may have bugs, and behavior can change while it is tested.
```
---
Loot the most important items first and make bag space for them.

Smart Loot takes money, quest items, and better gear before junk, then deletes cheaper bag items only when that loot is worth more. It works on Retail, WoW Forever, and Classic Era.

## Features

* Loots money, quest items, and higher-value gear first
* Makes bag space by destroying cheaper junk when the loot is worth more
* One destroy-to-loot pair at a time
* Classic Era: **Destroy Item**, then click the corpse again; Forever and Retail: **Destroy and Loot**
* Auto-destroy when looting, up to Grey, White, or Green
* Destroy junk from Grey items, Baganator, or RestedXP
* Protect items (shift-click a bag item) and crafting reagents
* Auctionator / TSM value when available
* Auto-close leftover loot
* Minimap button
* Edit Mode on Retail

## Commands

| Command | Action |
| --- | --- |
| `/smartloot` or `/sl` | Toggle the options window |
| `/smartloot enable` / `/smartloot on` | Enable the addon |
| `/smartloot disable` / `/smartloot off` | Disable the addon |

## Install

1. Download from CurseForge / WowUp, or clone this repository into `Interface/AddOns/SmartLoot`.
2. Enable **Smart Loot** in the addons list.
