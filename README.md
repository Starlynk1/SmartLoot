# Smart Loot

World of Warcraft addon that loots the most important items first and makes bag space for them.

**Author:** Starlynk  
**Version:** 0.1.1  
**License:** [GNU GPL v3](LICENSE)

## Clients

- Retail (12.1)
- Forever (1.60)
- Classic Era (1.15)

## Install

Place this folder in `Interface\AddOns\SmartLoot`, then enable **Smart Loot** on the character select screen.

In-game commands: `/smartloot` or `/sl`.
